# Charitha Raghavaraju — Portfolio

Personal site for Charitha Raghavaraju, Machine Learning Engineer.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js (App Router), TypeScript, and Tailwind CSS. Page copy lives in `src/content/` so facts can be updated without changing layout.
